# Version 2.26 – Consistent species visual identity

- Repeated växtceller of the same botanical species now share the same deterministic mass colour and fill-pattern grammar.
- Species identity is based on the botanical binomial, so cultivar labels do not create accidental visual variants.
- Generated botanical symbols use a fixed orientation and species-stable pigment.
- Fill motifs are now more legible and differentiated: stipple, diagonal hatch, curved bands, paired leaf/diamond forms, wave lines and cross marks.
- Similar bloom colours are separated using controlled hue and lightness shifts.
- Added regression coverage for stable species-level visual identity.
